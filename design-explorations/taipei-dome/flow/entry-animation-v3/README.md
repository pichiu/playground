# 入經藏進場動線 版本 3：兩路直進

西一＋桃竹 1,609 人（9 大隊 × 6 列，每大隊 3 列白衣、3 列藍衣）從 B1 看台 139–145 區的休息區離座。**白衣一路、藍衣一路**，照大隊 1→9 直接走 B1 走廊、下樓梯，到 B2 後白衣散成北三路、藍衣散成南三路，在西一入口前切齊、一路接續六路進場，到場內身分證位置。不進 B2 集結區，也不在樓梯或走廊候隊。

這是與現行版本 2c（`../entry-animation/`）並存的另一個方向，方便對照。2c 不動。設計文件：`../../../../docs/superpowers/specs/2026-10-22-entry-plan-v3-design.md`。

## 規則（一句話版）

白衣走靠看台的 A 路、藍衣走外側的 B 路；每一路三列交錯排隊（每列排大的先，三列輪流各出一人）；白衣依序用出口 139 → 140 → 141 → 142，藍衣用 142 → 143 → 144 → 145，**出口坐滿才換下一個**，所以任何時刻白衣的出口比藍衣近、兩路不交叉。

| 路 | 出口與人數 |
|---|---|
| A（白衣、靠看台） | 139 206 → 140 291 → 141 259 → 142 53 |
| B（藍衣、外側） | 142 202 → 143 185 → 144 198 → 145 215 |

- 142 兩路共用：藍衣大隊 1–3 先從上排出，白衣大隊 9 最後從下排出，中間約 4 分鐘沒人走。
- 換口點落在大隊中間，共 18 列分坐兩個出口（2c 不允許，版本 3 允許；大隊不拆的排法座位不夠）。
- 下樓後就是三白三藍六路。大隊 1 先在西一入口前每條線集合 10 人、**六條線切齊**後進場（0.4 秒一位，同 2c）；之後**一路接續**，誰到門前就接著走，不再分大隊停下（過門後還有迴廊）。只有這頭一批 59 人在門前等，最久約 7.8 秒。
- 全長約 362.6 秒（2c 260.5 秒）：樓梯每 0.4 秒只過 2 人。第一位過西一入口在第 25.6 秒（2c 第 130 秒）。
- 沒有中途緩衝：任何一人延誤，後面整路跟著延誤；出口幹部照名單、照時間一個一個放人。

## 怎麼看

頁面讀同一份 `data.json`，要經由網頁伺服器開啟（GitHub Pages，或在本資料夾 `python3 -m http.server`）。

| 頁 | 給誰 | 內容 |
|---|---|---|
| `index.html` 總覽 | 所有人 | 規則、出口 × 兩路、樓梯序、出口用量、檢核結果、下載 |
| `console.html` 指揮台 | 企劃投影 | 滿版地圖與隊伍線；時間軸：大隊 1–9 下樓梯、大隊 1–9 進場 |
| `me.html` 我的路 | 每一位菩薩（手機） | 輸入列、排，六步：起、出、走、集（門前）、進、到 |
| `score.html` 總譜 | 企劃筆電 | 54 列 × 時間，依樓梯序排列 |
| `handout.html` 講義 | 幹部（印 A3） | 六個關鍵時刻 |
| `captain.html` 口令卡 | 大隊長（手機） | 逐大隊八個口令（含門前出發）與六列狀態 |
| `exit.html` 出口帶隊卡 | 休息區出口幹部 | 逐出口由上排往下的帶隊順序、換口與空檔、整張座位圖 |

`seats.csv` 一人一列，欄位同 2c；「集結區」欄一律「門前集合（B2）」。

## 聲明

時間是動畫節奏（1 單位 ≈ 7.6 m、步速 1.1 單位/秒、同一路相鄰 0.4 秒），不是現場秒數；碰撞檢查是圖面點距（0.03 單位），不是人體寬度或通道容量認證；座位、看台幾何、走道口、樓梯 L 形、西一入口與場內路徑沿用 2c 的示意圖面。實際依企劃現場指示。
