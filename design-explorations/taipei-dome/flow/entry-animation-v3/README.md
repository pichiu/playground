# 入經藏進場動線 版本 3：兩路直進

西一＋桃竹 1,609 人（9 大隊 × 6 列，每大隊 3 列白衣、3 列藍衣）從 B1 看台 139–145 區的休息區離座。**白衣一路、藍衣一路**，照大隊 1→9 直接走 B1 走廊、下樓梯，到 B2 後白衣散成北三路、藍衣散成南三路，在樓梯口到西一入口這段走廊（舞台後方）排成六條線的門前隊伍；每個大隊排滿才一排緊跟一排並肩進門，在沿牆迴廊停好等下一大隊排滿，再北行進到場內身分證位置。不進 B2 集結區，也不在樓梯或 B1 走廊候隊。

這是與現行版本 2c（`../entry-animation/`）並存的另一個方向，方便對照。2c 不動。設計文件：`../../../../docs/superpowers/specs/2026-10-22-entry-plan-v3-design.md`。

## 規則（一句話版）

白衣走靠看台的 A 路、藍衣走外側的 B 路；每一路三列交錯排隊（每列排大的先，三列輪流各出一人）；白衣依序用出口 139 → 140 → 141 → 142，藍衣用 142 → 143 → 144 → 145，**出口坐滿才換下一個**，所以任何時刻白衣的出口比藍衣近、兩路不交叉。

| 路 | 出口與人數 |
|---|---|
| A（白衣、靠看台） | 139 226 → 140 291 → 141 259 → 142 33 |
| B（藍衣、外側） | 142 222 → 143 185 → 144 126 → 145 267 |

- 保留不坐（10/23）：139 留 34 席給台東（第 1–10 排 1–3 號、第 11–12 排 4–5 號，這兩排由 4 號起）、144 第 1–6 排 72 席；可用席合計 1,615，空位只剩 145 的 6 席。139 第 1 排 1–5 號原本標成不能坐，對照企劃座位表（2025.04.10「B1外野座位席ok」）其實是視線不良處，可以坐（`plan.seat_kind`）。
- 142 兩路共用：藍衣大隊 1–3 先從上排出，白衣大隊 9 最後從下排出，中間約 4 分鐘沒人走。
- 換口點落在大隊中間，共 18 列分坐兩個出口（2c 不允許，版本 3 允許；大隊不拆的排法座位不夠）。
- 下樓後就是三白三藍六路，在 B2 排成**門前隊伍**（每條線前後約 0.57 m，最多放一個大隊）。每個大隊從新的一排開始，**整個大隊排滿才出發**，一排六人並肩、一排緊跟一排離開隊頭（排距約 1.7 m）。
- **迴廊候隊**：每個大隊進門後在**沿全壘打牆內側的迴廊停好**（隊頭停在北轉前、後面往回排，排距約 1.3 m），**等下一個大隊在門前隊伍排滿才繼續走、進列**；下一個大隊緊跟在後進門，到迴廊停好。所以任何時候都是「迴廊裡一個大隊等進列、門前一個大隊在排」。最後一個大隊（大隊 9）後面沒人，不停。
- **整排轉彎（wheel turn）**：一排六人從隊頭到自己大隊的列區南緣**全程並肩**：左轉進西一入口、穿過門洞、右轉沿全壘打牆內側、左轉北行、沿舞台邊北上。舞台在大隊 1–4 列區西側是 11 階的階梯，整排不往東繞，靠舞台的第 1 路最多走上 3 階、第 2 路 1 階，其餘四路在地面。轉彎時像行進隊伍一樣整排一起轉：內圈走小步、外圈走大步，轉過來仍是六人並肩，不會變成斜線或一個一個。第 1 路（白衣、列 6k−5）永遠在行進方向左側：隊伍裡在東、門洞裡在北、北行時在西，進列時正好對到大隊第一列。間距在門前、門洞與沿牆段是 0.08 單位（牆和舞台南翼之間扣掉舞台淨距只剩約 0.45），北轉時漸變為座位列距 0.13。北行時整排會壓過後面大隊還空著的座位。
- **梯次進列**：舞台階梯和最前排座位（pai 1）之間只有約一人寬（扣掉 0.15 舞台淨距後 0.12–0.35 單位），整排右轉進列放不下。所以到了自己大隊列區南緣，每人從自己那一路沿兩欄之間的空隙往北、轉進自己那一列往東到位；座位在自己那一路西側的（多半是每大隊最後幾排、靠舞台）沿列區南緣的空隙往西，再從座位旁的空隙進列。兩欄、兩列之間的空隙離任何座位都是半格，所以不會擦過已坐好的人。
- 樓梯上一個接一個緊跟，每路 0.2 秒一人。頁面不顯示任何時間（播放進度用百分比、口令照順序編號），動畫時間只是節奏示意，不拿來和 2c 比快慢。
- 沒有中途緩衝：任何一人延誤，後面整路跟著延誤；出口幹部照名單、照時間一個一個放人。

## 怎麼看

頁面讀同一份 `data.json`，要經由網頁伺服器開啟（GitHub Pages，或在本資料夾 `python3 -m http.server`）。

| 頁 | 給誰 | 內容 |
|---|---|---|
| `index.html` 總覽 | 所有人 | 規則、出口 × 兩路、樓梯序、出口用量、檢核結果、下載 |
| `console.html` 指揮台 | 企劃投影 | 滿版地圖與隊伍線；時間軸：大隊 1–9 下樓梯、大隊 1–9 進場 |
| `me.html` 我的路 | 每一位菩薩（手機） | 輸入列、排，六步：起、出、走、集（門前隊伍）、進、到 |
| `score.html` 總譜 | 企劃筆電 | 54 列 × 時間，依樓梯序排列 |
| `handout.html` 講義 | 幹部（印 A3） | 六個關鍵時刻 |
| `captain.html` 口令卡 | 大隊長（手機） | 逐大隊八個口令（含門前隊伍出發）與六列狀態 |
| `exit.html` 出口帶隊卡 | 休息區出口幹部 | 逐出口由上排往下的帶隊順序、換口與空檔、整張座位圖 |
| `diorama.html` 3D 模型 | 所有人（說明用） | 黏土微縮模型 3D 動畫：1,609 人從看台下樓、門前隊伍、整排轉彎進門、迴廊候隊、北行進列；章節、跟隨一列或一個人、搜尋列排。需要 WebGL，three.js 從 cdn.jsdelivr.net 載入。這個檔由 `build/diorama.src.html` 以 `python3 -I build/inline.py` 產生，不要直接改 |

`seats.csv` 一人一列，欄位同 2c；「集結區」欄一律「門前隊伍（B2）」。

## 聲明

時間是動畫節奏（1 單位 ≈ 7.6 m、步速 1.1 單位/秒、樓梯同一路相鄰 0.2 秒、排滿後 0.2 秒一排），不是現場秒數；碰撞檢查是圖面點距（0.03 單位），不是人體寬度或通道容量認證；座位、看台幾何、走道口、樓梯 L 形、西一入口與場內路徑沿用 2c 的示意圖面。實際依企劃現場指示。
