# 版本 3 建置管線

三支腳本串起來，全部確定性，可重現：

```bash
cd build
python3 plan.py  base.json plan.json                           # §3.1–3.3：兩路交錯、出口坐滿就換、出口 FIFO 配座（秒級）
python3 build.py base.json plan.json ../data.json ../seats.csv  # §3.4–3.6：路線、一個時鐘的拉式排程、整排並肩（§3.4c）、碰撞避讓、meta.checks（約 2 分鐘）
python3 check.py ../data.json                                   # §4：檢核全部從 persons / restSeats 重算並與 meta.checks 比對；未通過 exit 1
python3 -I inline.py                                            # 3D 模型頁：由 diorama.src.html 產生 ../diorama.html（改 src 後要重跑）
```

3D 模型頁另可產生 claude.ai artifact 版（內嵌 data.json，不進 git）：`python3 -I inline.py --artifact OUT.html [../data.json]`。

`§` 指設計文件 `docs/superpowers/specs/2026-10-22-entry-plan-v3-design.md`。`plan.json` 是中間檔，不進 git。`build.py --no-avoid` 跳過避撞與檢核。

### 整排轉彎（wheel turn）改了哪些門檻、為什麼（10/25，設計文件 §3.4c）

- **「隊頭到西一入口一排一起 2 秒」→「t.gate = 自己穿過全壘打牆的時刻 ± 0.01」**：舊路線是隊頭到版本 1 收攏點的直線，固定 2 秒。新路線整排沿中心線轉進門，每條線穿牆時刻不同：左轉時內圈 lane 0 先過，相對 t.enter 是 1.40 秒，外圈 lane 5 是 1.56 秒（`meta.turnT` 記最慢那條）。`t.gate` 的語意維持「過西一入口」，me.html 的六步邊界不受影響。
- **同排離開隊頭差、排距的容許 0.16 → 0.01；西一入口拍距下限 0.44 → 0.59**：舊的 avoid 會把個人時間線平移最多 0.15 秒，所以留了 0.16。新做法整排並肩段所有排共用一個速度剖面，不平移時間線，只剩四捨五入，所以收緊。
- **「過門後全程步速」→「離開隊頭之後不快過步速、不停；分出之後步速」**：整排轉彎時內圈依半徑比放慢（第一個左轉內圈最慢 0.3 單位/秒），直線段六人都是步速。進列段的避撞只放慢橫走那一段，最低 0.7 倍。
- **新增「穿過已坐好的人」**：舊碰撞只看門前隊伍站定的人。新路線北行時整排壓過後面大隊的座位、進列時會經過同大隊別人的座位，這一項證明經過時那些座位都還空著。

### 迴廊候隊與階梯改了哪些門檻、為什麼（10/25，設計文件 §3.4d）

- **排距 0.6 → 0.2 秒；西一入口拍距下限 0.59 → 0.19、大隊內上限 1.2 → 0.8**：每個大隊排滿門前隊伍才出發，一排緊跟一排。0.2 秒是掃描出來的：0.13 秒（約 1 m）時，往西橫走一欄 0.12 秒和下一排同步，在欄間空隙大量相撞。
- **西一入口大隊間空檔 12 → 16 秒**：下一大隊要在門前隊伍排滿才進門，實測最長 15.2 秒。
- **「大隊 1 排滿才出發」→「每個大隊排滿才出發」**。
- **「離開隊頭之後不停」→「除了自己的迴廊候隊時段不停」**，並新增「迴廊候隊」一項驗停的位置、時段與「等下一大隊排滿」。
- **離舞台 0.15 加階梯例外**：舞台東側是 11 階的階梯（每階約 0.055 單位）。北行段不往東繞，靠舞台的第 1 路最多上 3 階、第 2 路 1 階；檢核數每一點往東跨過幾條舞台線，階梯段最多 3 條、其他地方 0 條，所以不會走進舞台；階梯以外仍要 ≥ 0.15。
- **橫走 5 欄改走座位東側那條空隙**：5 欄 0.598 秒 ≈ 3 排 × 0.2 秒，會在第 0 路那條空隙碰上 3 排之後的第 0 路。

### 北行改走第 5–10 排直線、不上階梯（11/7，設計文件 §3.4e）

- **北行中心線**：沿牆段轉北之後一條直線往北（中心線在第 8 排那一欄），六路走第 5–10 排地標東側緊鄰的欄間空隙。不再沿舞台邊南段欄 1 → 中段欄 4 → 北段欄 3，北轉圓角 0.6 → 0.45（大隊 9 的列區南緣在北轉弧結束處以南）。
- **大隊 9 也在北行直線上分出**：舊版大隊 9 在沿牆段分出、斜切進列；現在每個大隊都在正北直線上分出。
- **走到自己那列再轉**：每人沿自己那一路直直往北到自己那一列。座位在東側的右轉沿列往東（同 3.4c）；座位在西側的在那一列南邊半格的列間空隙往西，到座位正南方往北半格進座位（舊版是在列區南緣一起往西）。
- **往西的人怎麼錯開人流**（`march.west_plan`）：同一排六人同時走到同一個 Y、每 0.2 秒一排，人流在跟著往北走的座標裡是欄距 × 0.22 的格點。等速沿空隙往西，每過一欄的節拍相同；要連過 4–5 欄時（第 5 路的座位在第 5 排以西）一定有一欄正好碰上某一排，沒有任何等速解。所以每人在每個座位欄上的折點可離空隙中線偏移 0、±0.015、±0.03（離座位列至少 0.036），平的那一段可放慢到 0.9／0.8／0.7 倍，斜的那一段走步速；在格點人流裡用 beam search 選離每個人都最遠的走法（單人推算最近 0.038）。
- **檢核**：`geometry` 拿掉階梯例外：離舞台 ≥ 0.15 全程適用，跨過的舞台線 0 條（`MAX_STEPS = 0`）。其餘門檻不變。結果：碰撞全 0，不靠避撞放慢任何人；全長 201.77 → 204.54 秒。

### 第 10 排切齊、整塊一起走、前面停後面也停（11/9，設計文件 §3.4f）

- **規則**：每人沿自己那一路走到自己那一列（`march.kind` 分三種）。座位在第 10 排那條線（`march.ALIGN_X`，第 6 路北行的空隙）以東的 `align`：往東走到那條線上自己那一列（`march.wait_point`）停下，同一排的 `align` 都到了才一起起步（`t.alignStart` → `t.alignEnd`）。座位在自己那一路與那條線之間的 `east`、在西側的 `west` 不等對齊。
- **整塊一起走、前面停後面也停**：大隊從迴廊整塊出發（每排 `RANK_GAP` 0.2 秒），之後同一大隊某一排在線上等對齊時（那一排最早走到線上 → 一起起步），後面各排還沒走到自己轉向點（`align` 是到線上）的人原地停住（`timeline` 的 `freeze`）。前一大隊停的時段，下一大隊離開迴廊之後也適用；最後一個大隊在隊頭也等（出發後 0.2 秒內會遇到停就等停完再走）。
- **往西進列的人最後排**（`plan_west`）：其他人的時間軸都定了，往西的人在「大隊的走路時鐘」（`BlockClock`：實際時刻扣掉停的時段，往西的人也跟著停）上排走法，障礙物是同一大隊其他人的實際軌跡；必要時在自己那一列轉角先等（`WEST_WAITS`）。
- **樓梯延後**：進場變慢，某個大隊下樓時門前隊伍放不下，就把這個大隊與之後的樓梯時鐘往後挪（`meta.stairDelay`，各大隊 8–24 秒）。
- **檢核變更**：
  - 新增 `block`：`t.waits` 裡每一段停都在同一大隊（或前一大隊）某一排等對齊的時段裡；往西者另可在轉角先等。
  - `pace`：站住只能是迴廊候隊、等對齊、`t.waits` 記的那幾段。
  - `formation`：τ 扣掉所有停；路徑點離平移線、排中心離中心線改看「離線多遠」（停幾十次後四捨五入累積的沿線時間差不算偏離）。
  - `lane_map`：只有 `align` 的人有 `t.alignStart／alignEnd`，同排一起起步、等的時候在線上。
  - `continuity`：樓梯交界扣掉 `stairDelay` 再比 7 秒；西一入口大隊間空檔上限 16 → 45 秒（下一大隊要等前一大隊離開迴廊，實測最長 38.9 秒）。
- **結果**：碰撞全 0（第 0 輪），全長 204.5 → 350.4 秒。
