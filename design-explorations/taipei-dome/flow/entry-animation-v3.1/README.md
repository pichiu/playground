# 入經藏進場動線 版本 3.1：B2 集合區（11/8 現場彩排修正）

以版本 3（`../entry-animation-v3/`）為底的獨立版本。版本 3 與舊版 2c（`../entry-animation/`）都保留不動，作為對照。

## 為什麼改

版本 3 假設下樓後在樓梯口到西一入口這段 B2 走廊（門前）排好一個大隊，再逐隊進場。11/8 現場彩排確認：**門前沒有足夠空間照原方案整隊**。所以不再把門前當主要緩衝，改用 2c「藍衣集結區」（2c 的 P2–P5，`../entry-animation/build/routes.py` 的 `ZONES`）所在的 B2 走廊——西一入口以南、沿走廊往深處到圖面盡頭——當**集合區**，第一至第九大隊各有一個集合位置，而且白衣、藍衣都在這裡整隊（2c 只放藍衣、一區兩個大隊各三路）。

> 名稱對照：需求中的「11 入口」就是資料與各頁的「西一入口」（`nodes.GATE6`，2c 時叫 6口）；「藍一集合區」就是 2c 的藍衣集結區。若現場另有一個「11 號入口」，請告知，路線要重畫。

## 新流程

1. **依既定順序下樓**（同版本 3）：白衣一路（A，靠看台）、藍衣一路（B，外側），大隊 1→9，每路三列交錯。
2. **前往 B2 集合區**：下樓後仍是兩路，白衣靠場側。在西一入口前（u 3.6 之前）兩路一起移到走廊外側的**通行帶**，經過入口前、沿著已整好的隊伍外側，一路走到集合區最深處。入口前、樓梯口只走路、不站人。
3. **兩路轉六路**：在集合區盡頭整路左轉 180°（白衣內圈），轉過來白衣仍在行進方向左側；白衣散成三路、藍衣散成三路，共六路。
4. **到所屬大隊位置整隊**：沿自己那一路往回走到自己大隊的集合位置。大隊 1 最靠西一入口、大隊 9 最深——和放行順序一致。每一路先到的站前面（隊頭＝每列排號最大那一位，同版本 3 的進門順序），所以沒有人穿過已站好的人；到位前中途不停，樓梯上不等。
5. **依既定順序放行**：大隊全員站定才放行，大隊 1→9。隊頭一排六人並肩先走，後面的排往前補到隊頭再走，一排緊跟一排（0.2 秒）；下一大隊第一排跟在上一大隊最後一排之後。
6. **從集合區轉彎前往西一入口**：沿 B2 往回走、**右轉**進西一入口（版本 3 是從北邊來、左轉進門）。
7. **進場到原定演繹位置**：進門之後與版本 3 相同（沿牆、北轉、沿舞台邊北行、分出、梯次進列），只是拿掉了「迴廊候隊」。

## 尚需現場確認（圖面不足，不編尺寸）

1. **集合區長度／容量**：圖面 B2 走廊從西一入口南側到圖面盡頭約 12 單位（約 90 m，示意）。九個大隊共 281 排，要排進去每路前後只能 0.04 單位（約 0.3 m）；以版本 3 門前隊伍的 0.075 單位（約 0.57 m）計需要約 21 單位。**「長向放得下第一至第九大隊」目前只是現場觀察，圖面沒有驗證，動畫的點距不能當容量。** 實際長度、每隊佔用長度要量。
2. **通行帶寬度**：圖面走廊帶只畫六路寬（±0.2 單位）；通行帶（偏移 −0.30／−0.38）畫在帶外，是假設。走廊要能在六路之外再留兩人並行。**這是本方案的前提**：若留不出來，後到的大隊會在集合區旁穿過先到的大隊（衝突位置：集合區全段，尤其大隊 1–3 那一段，後面八個大隊都要經過）。
3. **B2 柱位（圖面衝突）**：圖面在集合區六路帶內有兩根柱——L8（截過的 B2 u 12.89、偏移 −0.17，大隊 7 的集合位置）與 L7（u 14.07、偏移 +0.18，大隊 8 的集合位置）。站在柱位上的格位（13 人）與後到大隊往回走經過的路線（約 1,070 人次）都碰到柱子；`check.py` 的「圖面柱位」一行列出明細，不算進通過與否。六路帶只有 ±0.2，旁邊繞不過去，圖面上無解；2c 在同一段也有這個衝突，版本 3 沒走到這裡。要現場確認柱子位置與柱旁淨寬。
4. **盡頭回頭空間**：兩路在集合區盡頭轉 180°（圖面圓心 u 17.55、外圈半徑 0.21 單位），圖面盡頭之後是什麼（牆、設備、其他出入口）不知道。
5. **入口前、樓梯口留空範圍**：集合區從西一入口帶南緣再往南 0.1 單位開始；實際要留多寬依現場。
6. **指揮位置（建議）**：休息區各出口幹部（照名單放人；集合區沒準備好就不放，人留在座位）；集合區盡頭轉彎處（分三路）；每個集合位置隊頭（確認站齊、放行）；西一入口右轉處。
7. **退場**：本版只處理入場；彩排時用的外門快速退場方式沒有放進來，不是正式場定案。

## 怎麼重算

```bash
cd build
python3 plan.py  base.json plan.json                           # 與版本 3 相同（逐位元相同）
python3 build.py base.json plan.json ../data.json ../seats.csv  # 路線、集合區、放行、整排轉彎、避撞、meta.checks（約 1 分鐘）
python3 check.py ../data.json                                   # 檢核全部重算；未通過 exit 1
python3 -I inline.py                                            # 由 diorama.src.html 產生 ../diorama.html
python3 verify_paths.py ../data.json ../../entry-animation-v3/data.json [圖.png]   # 與版本 3 逐人比對、大隊 1／5／9 左右與連續性
```

見 `build/README.md`。

## 聲明

時間是動畫節奏（1 單位 ≈ 7.6 m、步速 1.1 單位/秒），不是現場秒數；頁面不顯示任何時刻。碰撞檢查是圖面點距（0.03 單位），不是人體寬度；集合區點距 0.04 單位只為把九個位置排進示意圖面，**不是現場通行時間或容量驗證**。座位、看台、樓梯、西一入口與場內路徑沿用前版示意圖面。實際依企劃現場指示。
