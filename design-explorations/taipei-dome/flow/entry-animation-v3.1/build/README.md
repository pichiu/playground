# 版本 3.1 建置管線（自版本 3 改：門前隊伍、迴廊候隊 → B2 集合區）

三支腳本串起來，全部確定性，可重現：

```bash
cd build
python3 plan.py  base.json plan.json                           # §3.1–3.3：兩路交錯、出口坐滿就換、出口 FIFO 配座（秒級）
python3 build.py base.json plan.json ../data.json ../seats.csv  # §3.4–3.6：路線、一個時鐘的拉式排程、整排並肩（§3.4c）、碰撞避讓、meta.checks（約 2 分鐘）
python3 check.py ../data.json                                   # §4：檢核全部從 persons / restSeats 重算並與 meta.checks 比對；未通過 exit 1
python3 -I inline.py                                            # 3D 模型頁：由 diorama.src.html 產生 ../diorama.html（改 src 後要重跑）
python3 verify_paths.py ../data.json ../../entry-animation-v3-archive/data.json [圖.png]   # 與版本 3 逐人比對、大隊 1／5／9 左右（以行進方向）與連續性
```

3D 模型頁另可產生 claude.ai artifact 版（內嵌 data.json，不進 git）：`python3 -I inline.py --artifact OUT.html [../data.json]`。

`§` 指設計文件 `docs/superpowers/specs/2026-10-22-entry-plan-v3-design.md`。`plan.json` 是中間檔，不進 git。`build.py --no-avoid` 跳過避撞與檢核。

## 版本 3.1 的檢核變更

- **新增「B2 集合區」（`assembly`，取代版本 3 的 `staging` 迴廊候隊）**：九個集合位置沿 B2 依大隊 1→9 由入口往深處、不重疊、從入口帶南緣之後開始；每人站在自己大隊位置、自己那一路（偏移 −0.2 + 0.08j，± 0.02：B2 折線在截過的 u 6.9 有折角，中心線倒圓角後最多離 0.02）、第 0 格在隊頭、相鄰兩格約一格；站定到放行一直在位置內；樓梯口到站定之間不停（含樓梯上，容許 0.05 秒四捨五入）；兩路在入口帶到集合區盡頭這段走通行帶（偏移 ≤ −0.26）；九個大隊全部站齊才開始放行、依序放行。另列出「動畫裡同時有人在集合區的大隊最多幾個」（11/9 改成九隊站齊才放行後是 9：九個集合位置同時都有人）。
- **步速**：集合位置裡只能在自己那一路站住或往前補，速度 ≤ `SLOW`（0.04 / 0.2）× 1.2（彎道外側那一路比中心線長）；離開隊頭之後不停（沒有迴廊候隊）。
- **一排六人**：排距以「經過大隊 1 隊頭的時刻」比（各大隊隊頭位置不同）；同一路前後兩人在集合位置裡 ≥ 0.75 格（彎道內側那一路比中心線短，最小 0.033 單位，仍大於碰撞半徑 0.03）。
- **並肩、lane 對應**：中心線時間 τ = t − t.enter + `headTau[大隊]`。
- 其餘（碰撞、巢狀、指派、路徑交叉、不斷拍、轉彎、幾何、座位、容量）門檻不變。

### 整排轉彎（wheel turn）改了哪些門檻、為什麼（10/25，設計文件 §3.4c）

- **「隊頭到西一入口一排一起 2 秒」→「t.gate = 自己穿過全壘打牆的時刻 ± 0.01」**：舊路線是隊頭到版本 1 收攏點的直線，固定 2 秒。新路線整排沿中心線轉進門，每條線穿牆時刻不同：左轉時內圈 lane 0 先過，相對 t.enter 是 1.40 秒，外圈 lane 5 是 1.56 秒（`meta.turnT` 記最慢那條）。`t.gate` 的語意維持「過西一入口」，me.html 的六步邊界不受影響。
- **同排離開隊頭差、排距的容許 0.16 → 0.01；西一入口拍距下限 0.44 → 0.59**：舊的 avoid 會把個人時間線平移最多 0.15 秒，所以留了 0.16。新做法整排並肩段所有排共用一個速度剖面，不平移時間線，只剩四捨五入，所以收緊。
- **「過門後全程步速」→「離開隊頭之後不快過步速、不停；分出之後步速」**：整排轉彎時內圈依半徑比放慢（第一個左轉內圈最慢 0.3 單位/秒），直線段六人都是步速。進列段的避撞只放慢橫走那一段，最低 0.7 倍。
- **新增「穿過已坐好的人」**：舊碰撞只看門前隊伍站定的人。新路線北行時整排壓過後面大隊的座位、進列時會經過同大隊別人的座位，這一項證明經過時那些座位都還空著。

### 迴廊候隊與階梯改了哪些門檻、為什麼（10/25，設計文件 §3.4d）

- **排距 0.6 → 0.2 秒；西一入口拍距下限 0.59 → 0.19、大隊內上限 1.2 → 0.8**：每個大隊排滿門前隊伍才出發，一排緊跟一排。0.2 秒是掃描出來的：0.13 秒（約 1 m）時，往西橫走一欄 0.12 秒和下一排同步，在欄間空隙大量相撞。
- **西一入口大隊間空檔 12 → 16 秒**：下一大隊要在門前隊伍排滿才進門，實測最長 15.2 秒。
- **「大隊 1 排滿才出發」→「每個大隊排滿才出發」**。
- **「離開隊頭之後不停」→「除了自己的迴廊候隊時段不停」**，並新增「迴廊候隊」一項驗停的位置、時段與「等下一大隊排滿」。
- **離舞台 0.15 加階梯例外**：舞台東側是 11 階的階梯（每階約 0.055 單位）。北行段不往東繞，靠舞台的第 1 路最多上 3 階、第 2 路 1 階；檢核數每一點往東跨過幾條舞台線，階梯段最多 3 條、其他地方 0 條，所以不會走進舞台；階梯以外仍要 ≥ 0.15。
- **橫走 5 欄改走座位東側那條空隙**：5 欄 0.598 秒 ≈ 3 排 × 0.2 秒，會在第 0 路那條空隙碰上 3 排之後的第 0 路。

### 北行改沿第 4–9 排地標、第 9 排對齊（11/9，設計文件 §3.4f）

- **北行往西一欄**：`march.NORTH_X` 由 `SEAT_X0 + 7·SP_SEAT`（第 8 排那一欄）改成 `SEAT_X0 + 6·SP_SEAT`（第 7 排那一欄），六路走第 4–9 排地標東側的欄間空隙。分出點、`tail`、`west_plan` 的往西橫走都由 `NORTH_X` 算，跟著移一欄（往西的人少過一欄、往東的多走一欄）。
- **北轉圓角 0.45 → 0.42**：北行線往西後，沿牆段延長線與北行線的交點往北移，0.45 的弧在 y 7.937 結束，已經越過大隊 9 列區南緣半格（7.961），大隊 9 沒辦法在北行直線上分出；0.42 的弧在 y 7.985 結束，內圈半徑 0.091 仍 ≥ `INNER_MIN` 0.08。
- **離舞台：第 1 路北行線兩側半格 0.15 → 0.10（`check.STAGE_MIN_NORTH`、`march.STAGE_MIN_NORTH`）**：最西的第 1 路在第 4 排東側空隙往北，經過舞台東側階梯旁（y ≈ 3.1）最近 0.111，大隊 3 第 1 路在那裡轉進列的彎也在 0.15 以內；不跨任何階梯線（`MAX_STEPS` 仍是 0）。例外只限 x 在那條線 ± 半格（`NORTH_LINE_TOL`），其他路段仍 ≥ `STAGE_MIN` 0.15。
- **第 9 排對齊（11/9 第二版：每一排都對齊；`build.align_sim`、`map.align`、`t.holdStart／t.holdEnd`）**：座位在第 10 排以東的人，`tail` 經過對齊點 (`march.ALIGN_X` = 第 9 排東側空隙, 列 Y)（第 6 路就在那條線上，轉角不倒圓）。每一排（同一大隊同一 slot、第 10 排以東的人）六人都走到對齊點才一起過線，下一排至少晚 `RANK_GAP`；過線之後並排往東、各自到位。第 1 列的路最長，所以第 2–6 列每一排都在線前等它。
  - **排隊模擬**：以 `ALIGN_DT` 0.01 秒的時間步模擬六路所有人（跨大隊），每人沿自己的名目路徑前進或停住（不快過名目速度剖面）。限制：(1) 同一路前面的人（共用路線那一段）至少 `ALIGN_GAP` 0.07，但不要求比名目間距（落後 `RANK_GAP` 秒）還遠——轉進西一入口、北轉時內圈的名目間距本來就小於 0.07；(2) 第 10 排以東的人在自己那一排放行前不過對齊點；(3) 進列時橫越別路北行線的交會點一次只給一邊走（往北的人或橫越的人，`CROSS_X` 0.045、`CROSS_N` 0.064；`CROSS_N` 小於半個列距，相鄰交會點不重疊，否則會互相卡住；停在範圍邊界上的人不算佔用）。模擬卡住（有排沒過線、有人沒到位）就停止建置。
  - 受限的那幾步記成排隊時段 `t.holdStart → t.holdEnd`（裡面可以停、可以慢）；`t.split`、`t.gate` 改成實際走到那一點的時刻。第 9 排與以內的人不對齊，被擋就等。
  - 放行規則不變（下一大隊緊跟）。企劃同意後面大隊在進門前等也可以，但模擬結果沒有人在進門前等：西一入口時刻與版本 3.1 第一版逐人相同。
  - 往西進列原本靠 `west_plan` 的偏移與放慢錯開「名目」人流；現在人流會排隊、時刻會變，改由上面的交會點規則處理（`west_plan` 的路線形狀仍保留）。
  - 效能：`march._check_stage` 改成 numpy 一次算；模擬裡每人的 λ 只在前進時更新。一次建置約 1 分鐘。
- **檢核**：`align` 改成驗每一排（第 10 排以東）六人同時過線（離開對齊點的時刻 = 那一排的 T ± 0.01）、各排依序且相距至少 `RANK_GAP`、過線後不再排隊；沒有排隊時段的人離開隊頭之後沒有停留點；列出排隊人數（含第 9 排以內）、進門前就開始排隊的人數。`pace`：排隊時段裡（從時段內開始的段）可以停、可以慢，不快過步速。`formation`、`lane_map` 只驗到開始排隊為止（之後中心線時間不能由 t 推）。`continuity` 的西一入口拍距不算在進門前就開始排隊的人（只驗順序）。結果：208 排；排隊 1,505 人（第 9 排以內 313）、最長 3.01 秒；進門前排隊 0；碰撞、穿過已坐好的人全 0；全長 271.03 → 271.45 秒。

### 北行改走第 5–10 排直線、不上階梯（11/7，設計文件 §3.4e）

- **北行中心線**：沿牆段轉北之後一條直線往北（中心線在第 8 排那一欄），六路走第 5–10 排地標東側緊鄰的欄間空隙。不再沿舞台邊南段欄 1 → 中段欄 4 → 北段欄 3，北轉圓角 0.6 → 0.45（大隊 9 的列區南緣在北轉弧結束處以南）。
- **大隊 9 也在北行直線上分出**：舊版大隊 9 在沿牆段分出、斜切進列；現在每個大隊都在正北直線上分出。
- **走到自己那列再轉**：每人沿自己那一路直直往北到自己那一列。座位在東側的右轉沿列往東（同 3.4c）；座位在西側的在那一列南邊半格的列間空隙往西，到座位正南方往北半格進座位（舊版是在列區南緣一起往西）。
- **往西的人怎麼錯開人流**（`march.west_plan`）：同一排六人同時走到同一個 Y、每 0.2 秒一排，人流在跟著往北走的座標裡是欄距 × 0.22 的格點。等速沿空隙往西，每過一欄的節拍相同；要連過 4–5 欄時（第 5 路的座位在第 5 排以西；11/9 起第 4 排以西）一定有一欄正好碰上某一排，沒有任何等速解。所以每人在每個座位欄上的折點可離空隙中線偏移 0、±0.015、±0.03（離座位列至少 0.036），平的那一段可放慢到 0.9／0.8／0.7 倍，斜的那一段走步速；在格點人流裡用 beam search 選離每個人都最遠的走法（單人推算最近 0.038）。
- **檢核**：`geometry` 拿掉階梯例外：離舞台 ≥ 0.15 全程適用，跨過的舞台線 0 條（`MAX_STEPS = 0`）。其餘門檻不變。結果：碰撞全 0，不靠避撞放慢任何人；全長 201.77 → 204.54 秒。
